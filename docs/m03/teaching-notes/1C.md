# Lesson 1C: static teaching notes

Two voices: a held foundation, timing and silence.

Static lesson notes that feed the later teaching retrofit. The website explains; the learner plays everything on their **own keyboard**. No toggles, reveals, quizzes or sound.

## C01 · The Held Foundation with Visiting Upper Notes
- **Status:** ART GENERATED + NATIVE READY (ART)
- **Placement:** 1C first two-voice introduction
- **Learning outcome:** See harmony as two independent voices, one continuous and one visiting.
- **How to read the picture:** Native static source 1C C01 lower C held 0–12s; upper E 2–4s, G 5–7s, D 9–11s; if native time ruler shown, exact event lengths above; no model timing labels.
- **On your own keyboard:** Explain voice as independent musical line and simultaneous notes as harmony; learner sustains C and alternates E G D if physically feasible.
- **Truth guard:** Do not insist C+E is a triad; no audio playback.
- **Files:** `public/soundscape/m03/art/C01.webp`, `public/soundscape/m03/native/C01-native.svg`, `public/soundscape/m03/native/C01-native.print.svg`

## C02 · Two Distinct Voices — One Scene
- **Status:** ART GENERATED + NATIVE READY (ART)
- **Placement:** 1C clarify role and polyphonic layering
- **Learning outcome:** Distinguish a stable foundation from independent upper melody even when both sound together.
- **How to read the picture:** Native lower/upper voice labels anchored at appropriate points with accurate source example C01 and separate faint keyboard positions.
- **On your own keyboard:** Point out that each color/strand represents a voice and there can be overlapping pitches; learner tries each line separately on own instrument then combines if able.
- **Truth guard:** Do not encode extra fictitious notes or let color alone carry voice identities.
- **Files:** `public/soundscape/m03/art/C02.webp`, `public/soundscape/m03/native/C02-native.svg`, `public/soundscape/m03/native/C02-native.print.svg`

## C04 · Early versus Late Entrance
- **Status:** ART GENERATED + NATIVE READY (ART)
- **Placement:** 1C timing and silence explanation
- **Learning outcome:** See that the same note entering at a different time changes a phrase's shape even when pitch remains.
- **How to read the picture:** Native timing labels from C02: E 2–6s over C 0–12; C03: E 7–11s over C 0–12. Both upper notes E at same pitch, only onset differs.
- **On your own keyboard:** Explain entrance, duration and silence; learner sustains C then plays E early and late in separate versions, noticing the change.
- **Truth guard:** Do not use animation or click-to-compare; both examples static on one lesson page.
- **Files:** `public/soundscape/m03/art/C04.webp`, `public/soundscape/m03/native/C04-native.svg`, `public/soundscape/m03/native/C04-native.print.svg`

## C07 · The Same 36 Seconds, Two Endings
- **Status:** ART GENERATED + NATIVE READY (ART)
- **Placement:** 1C late lesson comparison after starting material learned
- **Learning outcome:** Recognize a shared musical journey but two distinct final possibilities.
- **How to read the picture:** Native 1C C04/C05 shared C 0–36s and upper E (8–12), G (15–19), D (23–27), B (29–32); only C04 adds upper C 33–35.8s. If there is an expectation prompt, compare only on later static step.
- **On your own keyboard:** Walk the shared four notes and final difference, then play two final options on real keyboard; listener decides how each works.
- **Truth guard:** Do not show final C on an earlier prediction page; source timings verified.

## C08 · Silence as Compositional Space
- **Status:** ART GENERATED + NATIVE READY (ART)
- **Placement:** 1C creative lesson before composition
- **Learning outcome:** Perceive gaps and waiting as purposeful elements of a two-voice idea.
- **How to read the picture:** Native annotation 'upper voice rests' at source C01 gaps, exact timing only if charted separately; no fake waveform.
- **On your own keyboard:** Learner plays a short idea with one pause; repeats without pause and notices different pacing.
- **Truth guard:** Silence in upper line is not total silence if lower foundation continues.
