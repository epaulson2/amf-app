# Lesson 1A: static teaching notes

Finding C, the white-key journey, and C as chosen home.

Static lesson notes that feed the later teaching retrofit. The website explains; the learner plays everything on their **own keyboard**. No toggles, reveals, quizzes or sound.

## A01 · One Note Becomes a Place
- **Status:** ART GENERATED + NATIVE READY (ART)
- **Placement:** 1A after opening real-keyboard setup, before note names
- **Learning outcome:** Understand that a played note can be a single stable musical event and that a picture can treat it as a reference.
- **How to read the picture:** Native key illustration may show one unlabelled white key being pressed here; simple static annotation: one sound remains, not a chord or an entire scale.
- **On your own keyboard:** Teach note as musical sound, listen to one note physically; ask what about it persists when held and how the sound's color might vary with the synth tone.
- **Truth guard:** No pitch-letter prerequisite; metaphor does not scientifically illustrate amplitude or frequency.

## A02 · Pitch versus Loudness
- **Status:** NATIVE READY (NATIVE) — reuses A01 art
- **Placement:** 1A definition of pitch before locating C
- **Learning outcome:** Tell apart high/low pitch from loud/soft volume.
- **How to read the picture:** Accurate actual neighboring-key example; rightward keyboard position conventionally higher, leftward lower. Labels 'higher/lower' and 'louder/softer' in different native visual axes.
- **On your own keyboard:** Describe which action changes pitch (play a more rightward key) and which changes volume (play softer/louder or change volume control); learner tries both on own synth.
- **Truth guard:** Do not ask the model to draw an oscilloscope or incorrect wave amplitude chart; keyboard's grouping deterministic.
- **Files:** `public/soundscape/m03/art/A01.webp`, `public/soundscape/m03/native/A02-native.svg`, `public/soundscape/m03/native/A02-native.print.svg`

## A03 · Find C by Two Black Keys
- **Status:** NATIVE READY (NATIVE) — M02 G02 accent reused; narrow layout A03-narrow
- **Placement:** 1A first named pitch and keyboard geography
- **Learning outcome:** Identify any C as the white key immediately left of each two-black-key group.
- **How to read the picture:** Draw full repeating two/three-black-key groups from keyboard geometry, two C highlights, small locator guides, native C labels; no hidden labels, no buttons, accurate E–F and B–C.
- **On your own keyboard:** Teach the two-black-key landmark and trace the left-adjacent white key; learner finds and plays multiple Cs on their own instrument.
- **Truth guard:** Keyboard remains a factual static illustration; a 'reveal the Cs' control from M02 pilot must not ship.
- **Files:** `public/soundscape/m02/art/G02-ACCENT-keyboard-light.webp (M02, reused)`, `public/soundscape/m03/native/A03-native.svg`, `public/soundscape/m03/native/A03-native.print.svg`, `public/soundscape/m03/native/A03-narrow.svg`, `public/soundscape/m03/native/A03-narrow.print.svg`

## A04 · C as Chosen Home / Concentric Tonal Center
- **Status:** REUSED ART + NATIVE READY (REUSE) — approved M02 G01 art reused; new static native labels
- **Placement:** 1A after finding C and learning contextual musical reference
- **Learning outcome:** See one chosen reference C and the surrounding visiting notes; understand that 'home' depends on music context.
- **How to read the picture:** Native C center and named D E F G A B visitor labels and a static correctly positioned return path, plus real C highlight beneath; legible explanation 'relationship map, not to scale'.
- **On your own keyboard:** Walk C→D→E then back to C with fingertips on synth; compare a phrase ending at G with one ending at C. Say the white keys alone do NOT prove C is home.
- **Truth guard:** Do not bake letters in model art, claim C drone proves C-major key, infer tone colors objectively.

## A05 · Seven Names, Ordered White-Key Journey
- **Status:** NATIVE READY (NATIVE) — wide and narrow layouts
- **Placement:** 1A immediately after A03 and before octave
- **Learning outcome:** Follow C D E F G A B C in correct order and distinguish white-key order from semitone size.
- **How to read the picture:** Exact eight white key positions, repeated higher C, visible E–F/B–C boundaries and no equal-chromatic-semitone implication. Two static layouts for narrow/wide screens.
- **On your own keyboard:** Read the letters in sequence while playing consecutive white keys from C to next C, then back. Notice where the black keys do and don't interrupt.
- **Truth guard:** Do not model-render any key or label; the route is visually ordered, not a measured radial spacing.
- **Files:** `public/soundscape/m03/native/A05-native.svg`, `public/soundscape/m03/native/A05-native.print.svg`, `public/soundscape/m03/native/A05-narrow.svg`, `public/soundscape/m03/native/A05-narrow.print.svg`

## A06 · Octave Return Spiral
- **Status:** ART GENERATED + NATIVE READY (ART)
- **Placement:** 1A after the eight-note white-key path
- **Learning outcome:** See that a higher C has the same note name but a genuinely higher pitch.
- **How to read the picture:** Two deterministic C keyboard positions separated by one octave; two independent static C labels and an upward pitch-arrow/spiral path registered to art.
- **On your own keyboard:** Describe same named family at a new height; learner plays lower then higher C and back, without learner-facing C3/C4/C5 numbering.
- **Truth guard:** Spiral is poetic recurrence, not a calibrated hertz graph; optional 2:1 frequency science belongs in documented enrichment.

## A07 · Ascending and Descending C-to-C
- **Status:** VARIANT READY (VARIANT) — variant of A05/A06

- **Learning outcome:** Distinguish going up an octave from returning down using the same note set.
- **How to read the picture:** Label direction up/right vs down/left with genuine ordered keys; two static views, not clickable trace.

## A08 · Two Endings: Away and Home
- **Status:** ART GENERATED + NATIVE READY (ART)
- **Placement:** 1A tonal-center comparison after A04
- **Learning outcome:** See a path that departs from chosen home and understand the effect of different endpoints.
- **How to read the picture:** Exact native educational example(s) shown as clearly authored practice rather than fabricated historical fixture. E.g. same first notes C–D–E, compare ending on G versus C, drawn as two static pathways with labels only after lesson explains comparison.
- **On your own keyboard:** Explain that context makes C a reference, but the listener can experience ending points differently; learner plays identical opening twice, finishing once on G and once on C, describes own response.
- **Truth guard:** Early version before any answer-prediction must be neutral; do not universally assign emotions to destinations.
- **Files:** `public/soundscape/m03/art/A08.webp`, `public/soundscape/m03/native/A08-native.svg`, `public/soundscape/m03/native/A08-native.print.svg`

## A09 · Drone: A Note That Stays While Others Visit
- **Status:** ART GENERATED + NATIVE READY (ART)
- **Placement:** 1A introducing sustained reference and visiting note
- **Learning outcome:** Understand 'drone' as one continuing held note under changing notes.
- **How to read the picture:** Native continuous C foundation label, separate E/G/D educational visitor labels if introduced; if showing actual historical A02 event, verify exact starting and duration from week1 fixtures first. No web-sound control.
- **On your own keyboard:** Explain which strand stays and which comes and goes, then sustain C with one hand or sustain pedal while playing one other note; if impossible physically, alternate playing notes and imagining C or use explicitly optional external reference.
- **Truth guard:** One C held is not by itself a full chord or proof of tonic; shapes not sound-wave measurements.
- **Files:** `public/soundscape/m03/art/A09.webp`, `public/soundscape/m03/native/A09-native.svg`, `public/soundscape/m03/native/A09-native.print.svg`

## A10 · Tiny Personal Melody and Pauses
- **Status:** ART GENERATED + NATIVE READY (ART)
- **Placement:** 1A first open-ended creation exercise
- **Learning outcome:** Use a handful of known notes to create a deliberate phrase with a resting point or change.
- **How to read the picture:** Native illustrative EXAMPLE melody e.g. C–D–E–C, explicitly marked as example rather than authoritative event fixture, with static keyboard callout and a gap marker; learner may use their own notes.
- **On your own keyboard:** Invite learner to make a three/four-note idea, repeat it with a pause or different final note and listen to what changed.
- **Truth guard:** Do not force recording/DAW account or an invented official source recording.
